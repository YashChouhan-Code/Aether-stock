## Introduction

Welcome to the **Modern Stock Management System**, a comprehensive full-stack web application designed to streamline inventory management, purchase orders, invoicing, and agency tracking for businesses. ## Project Overview

The application consists of:

- **Frontend**: A React-based single-page application (SPA) with routing, charts, and interactive components.
- **Backend**: A Node.js Express server providing RESTful APIs for data management.
- **Database**: SQLite for lightweight, file-based data storage.
- **Deployment**: Ready for production with Vite build tools and PWA support.

## Key Features

### 1. Dashboard

- **Real-time Analytics**: Displays total items, stock levels, out-of-stock alerts, and performance metrics.
- **Charts and Graphs**:
  - Area chart for expenses and profits over time.
  - Pie chart showing stock status (in stock vs. out of stock).
  - Bar chart for top-performing stores or agencies.
- **Quick Stats**: Cards showing total items, orders, stock quantity, and alerts.

### 2. Item Master

- **CRUD Operations**: Create, read, update, and delete items.
- **Item Details**: Name, category, stock quantity, unit, status, and GST percentage.
- **Filtering and Search**: Easily find items by category or status.

### 3. Purchase Orders

- **Order Management**: Create and track purchase orders from suppliers.
- **Approval Workflow**: Approve pending orders.
- **Status Tracking**: Monitor order status (pending, approved).

### 4. Invoicing

- **Invoice Creation**: Generate invoices for customers with details like customer name, contact, date, total amount, and status.
- **Payment Tracking**: Mark invoices as paid.
- **History**: View all invoices in chronological order.

### 5. Agencies

- **Agency Management**: Add and manage supplier agencies.
- **Performance Scores**: Track agency performance with scores.
- **Contact Information**: Store agency names and contacts.

### 6. Reports

- **Data Visualization**: Generate reports on stock, sales, and performance.
- **Export Options**: (Future feature) Export data to PDF or CSV.

### 7. Settings

- **Theme Toggle**: Switch between light and dark modes.
- **Configuration**: Set low stock thresholds and GST options.

## Technology Stack

- **Frontend**:
  - React 19 (with hooks and functional components)
  - React Router DOM for navigation
  - Recharts for data visualization
  - Lucide React for icons
  - Vite for build tooling and development server
  - CSS for styling with dark theme support

- **Backend**:
  - Node.js with Express.js
  - RESTful API design
  - CORS and Body Parser for request handling

- **Database**:
  - SQLite3 for data persistence
  - Schema includes tables for items, purchase orders, invoices, agencies, and settings

- **Other Tools**:
  - ESLint for code linting
  - PWA support with service workers

## How to Run the Project

1. **Prerequisites**: Node.js installed.
2. **Clone/Setup**: Navigate to the project folder.
3. **Install Dependencies**:
   - Frontend: `npm install` (in root)
   - Backend: `cd backend && npm install`
4. **Run Backend**: `npm start` (from root or backend folder).
5. **Run Frontend**: `npm run dev` (from root).
6. **Access**: Open http://localhost:5173 for frontend, backend on port 5000.
